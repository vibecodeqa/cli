# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in VibeCode QA, please report it responsibly:

1. **Do NOT** open a public GitHub issue
2. Email: security@vibecodeqa.online
3. Or use GitHub's private vulnerability reporting: https://github.com/vibecodeqa/cli/security/advisories/new

We will acknowledge your report within 48 hours and provide a fix timeline within 7 days.

## Scope

- The CLI tool (`@vibecodeqa/cli`)
- The GitHub App worker (`api.vibecodeqa.online`)
- The web dashboard (`app.vibecodeqa.online`)

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | Yes       |
| < Latest | No — upgrade to latest |
